# 03 · 生图细节

## 工具

优先内置imagegen，无需API key，不擅自切换CLI/远程模型。读当前imagegen技能与工具文档；本地图未看过先view_image。用本轮3–4张参考照片的真实路径，批准样张可另作风格基准。不得同时传referenced_image_paths和num_last_images_to_include。

~~~javascript
// @exec: {"yield_time_ms": 120000, "max_output_tokens": 1000}
const r = await tools.image_gen__imagegen({
  prompt: finalPrompt,
  referenced_image_paths: referencePaths,
  transparent_background: false
});
generatedImage(r);
~~~

正常纸张照片无透明背景。长调用按当前运行环境等待，不输出完整结果/base64。样张批准后可并行生成独立页，逐页保存核对，不盲目整套重试。

## 四类细节

| 类别 | 提示词应具体指定 |
|---|---|
| 笔迹 | 粗细、紧凑/松散、连笔、收笔、倾斜、宽高；重复字符每次自然不同，非复制字模。 |
| 数学 | 手写分数、上下标、积分号/上下限、求和、根号、行列式、共轭范围；不能抄LaTeX命令。 |
| 纸张 | 本轮要求的白纸/红线等，无点阵/方格等约束；无授权不加学校标识、姓名或签名。 |
| 摄影和墨 | 光源方向、色温、柔影、轻微透视和纸张弯曲；墨和纸共享亮度/焦点/纹理，有笔压与轻微渗墨。 |

这是参考条件下生图，不是个人笔迹模型训练，不承诺逐字复刻/平台判定。
“印刷感”：实际重画笔画，不仅加纸背景/噪点，避开印刷中文和LaTeX数学体。
“漂浮”：不用锐利纯黑文字叠柔焦纸；要求同一成像过程、纤维中的墨，无描边、发光、浮雕、字的投影。
“更乱”：改变具体笔画和布局，不只旋转整页，不改变符号语义。

## 逐页看图

核对题号/小问/步骤/结论完整，分子分母、根号指数、下标、行列式、正负号、极点阶数、分支和参数正确。共轭线反复误画时改用更易呈现的正确证明，如CR，不接受歧义式。阴影不遮公式、不裁字，无漂浮或误留点阵/彩色。不靠造错误、漏字模拟人类。

目标分辨率不代表实际尺寸，保存后读取实值。原图复制到指定目录，保留旧版，SHA-256核对复制。Python仅作只读格式/尺寸/哈希检查与文件复制；内容编辑继续用imagegen，除非用户明确指定其他方式。
