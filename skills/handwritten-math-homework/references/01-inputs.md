# 01 · 输入与样张

必须有3–4张清晰、用户有权使用的手写照片，至少一张含数学。尽量覆盖数字、x/y/z/u/v、分式、上下标、根号和本题涉及的积分/求和/共轭。现有3–4张可用就复用；严重裁切、模糊或不足3张才请补充。

需要准确课程/作业、完整题目、保存位置，以及仅生图或上传到等待提交的范围。顶部作业截图不等于完整题干。纸张、颜色、笔粗、松散度、光源、阴影和角度按用户本轮最新要求，不把灰度或暖光设为通用默认。

新风格先做一页，包含正文、重复字及代表性公式，用户确认后批量生成。已确认样张可直接复用。

| 反馈 | 修改 |
|---|---|
| 像电子版印在纸上 | 全部笔画重写，字形、连笔、间距、基线和公式布局自然变化，去印刷数学体。 |
| 不同字要有变化 | 重复字、字母、数字每次落笔不同，保持同一个人的习惯，不复制字模。 |
| 字漂浮 | 墨与纸共享透视、弯曲、明暗、焦点和噪声，有细微渗墨/笔压，无字的投影或发光。 |
| 再乱一些 | 增加大小、倾斜、字距、行距、缩进和连笔变化，符号语义保持清晰。 |
| 换一份解法 | 先推导另一个正确方法或表达，结论唯一时保持一致，不造错误来求不同。 |

参考照只决定风格，不复制其中旧题、错误、姓名和无关文字；不将个人照片或附件临时路径永久打包进技能。
